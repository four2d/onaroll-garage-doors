# On A Roll — social archive

Dated copies of approved weeks from the Jon review board.

## After a week is posted

1. On the board, with all three posts approved, tap **Archive week**.
2. Your browser downloads:
   - `YYYY-MM-DD.html` — self-contained week page (creatives + captions)
   - `weeks.json` — updated index
3. Move both into this `archive/` folder (replace `weeks.json`).
4. Commit and push so GitHub Pages serves them.

Browse at: https://four2d.github.io/onaroll-garage-doors/archive/
